# Zarirangold: Gold Platform

> 🔒 **Showcase only.** The source code is private (client project at Utab Pars).

**Live:** [zarirangold.com](https://zarirangold.com)

A web platform for a gold business, with a **React** frontend and a **Laravel** backend.

## ✨ Highlights
- React dashboard with charts and data tables
- Jalali (Persian) dates and number formatting
- Form handling and validation with React Hook Form
- Server data fetching and caching with React Query
- Laravel backend API

## 🛠 Tech stack
React · React Router · React Query · React Hook Form · Chart.js · Bootstrap · Laravel · PHP

## 👤 My role
Frontend development of the React app and its integration with the Laravel API.
